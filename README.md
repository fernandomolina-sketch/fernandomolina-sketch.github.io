# Aero C-Suite · página de firma

Copia pública de `firma/` del repositorio de Aero C-Suite: HTML, CSS y JavaScript estáticos, sin secretos ni
llamadas de red. Aquí el verificador da de alta su llave de acceso (Face ID) y firma las aceptaciones de
la Fase IV. Cada 6 horas, y justo antes de emitir cada enlace de firma, se comprueba que cada fichero
servido es byte a byte el de master; si difiere, no se emite enlace.
